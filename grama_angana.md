# Grama Angana

Grama Angana is an Android application developed to support digital village and community service management through a centralized mobile platform. The application is designed to help users access local services, manage applications, receive updates, and request community hall bookings through a simple and user-friendly interface.

## Features

- User Authentication using Firebase Authentication
- Dashboard-based navigation system
- Community service application management
- Hall booking module
- User profile management
- Settings and logout functionality
- Firebase Firestore integration
- Modern UI using Jetpack Compose
- Structured Android navigation flow

## Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/zainabImir/grama-angana.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Add your `google-services.json` file inside the `app` folder.

5. Connect Firebase Authentication and Firestore.

6. Run the application on an emulator or Android device.

## Firebase Setup

The project uses Firebase services for authentication and cloud database support.

### Required Firebase Services

- Firebase Authentication
- Firebase Firestore Database

### Firebase Configuration

1. Create a Firebase project.
2. Register the Android application.
3. Download `google-services.json`.
4. Place the file inside the `app` directory.
5. Enable Authentication and Firestore Database.
